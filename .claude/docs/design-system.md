# Charte graphique

## Couleurs
- Primaire : #005a5c (ex. boutons, actions principales)
- Secondaire : #007959
- Fond : #282828
- - Cellule vivante : dégradé de #007959 à #005a5c selon l'âge de la cellul
- Cellule morte / grille : #1c1c1c

## Typographie
- Police : Roboto Mono
- Tailles : titres 16px, texte courant 12px

## Espacements
- Unité de base : ex. 4px ou 8px (multiples pour marges/paddings)

## Composants
- Boutons : rayon de bordure, états hover/disabled
- Grille de simulation : couleur de fond, couleur des cellules, épaisseur de bordure

## Règles
- Toujours utiliser les variables/tokens définis ici (pas de couleur en dur dans le code)
- Respecter le contraste minimum (accessibilité, ratio WCAG AA)
