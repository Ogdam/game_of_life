# Stack technique

 ## FrontEnd :
  - Framework React 19+, Vite, pixi.js
  - UI : Bootstrap 5, bootstrap-icons
  - State management : Zustand
  - Tests : Jest / Vitest,  couverture minimum 70%
  - Formatter : Prettier
  - Linter : ESLint
  - Communication : WebSocket + REST (fetch)

 ## BackEnd :
  - Langage/framework : python 3.9+, FastAPI
  - Base de données : PostgreSQL 16
  - Tests : pytest,  couverture minimum 70%
  - Formatter : Black
  - Linter : Pylint
  - Communication temps réel : WebSocket natif (FastAPI)

 ## Déploiement :
  - Dev local : docker-compose
  - Orchestration au-delà du dev local : Kubernetes (Deployments + Services + Ingress)
  - Ingress controller : nginx-ingress
