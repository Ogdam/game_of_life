## Sobriété token
- Lire uniquement les fichiers/sections nécessaires à la tâche
- Ne pas relire un fichier déjà lu dans la session sauf modification
- Préférer Grep/Glob à la lecture complète de fichiers

## Qualité code
- Fonctions courtes (<50 lignes), noms explicites
- Pas de sur-abstraction, pas de code mort, pas de commentaires redondants
- Réutiliser les patterns existants avant d'en créer un nouveau
